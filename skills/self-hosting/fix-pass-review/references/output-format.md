# Output Format: Fix-pass Review

Return Markdown with these sections in this order:

1. `## Original Findings`
2. `## Resolution Status`
3. `## Fix-pass Scope`
4. `## Scope Check`
5. `## Source Trace`
6. `## Verification Follow-up`
7. `## Recommendation`

Mark each original finding as `resolved`, `partially_resolved`, or `unresolved`.
