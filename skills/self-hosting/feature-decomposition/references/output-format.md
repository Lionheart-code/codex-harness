# Output Format: Feature Decomposition

Return Markdown with these sections in this order:

1. `## Request Summary`
2. `## Goals`
3. `## Non-goals`
4. `## Assumptions And Open Questions`
5. `## Proposed Task Contracts`
6. `## Dependency And Risk Order`
7. `## Recommended First Active Task`

If blocked, replace sections 5 through 7 with `## Blockers`.
