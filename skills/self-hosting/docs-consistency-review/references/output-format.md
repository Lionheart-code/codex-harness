# Output Format: Docs Consistency Review

Return Markdown with these sections in this order:

1. `## Docs Reviewed`
2. `## Contradictions Found`
3. `## Minimal Corrections`
4. `## Source Trace`
5. `## Docs Freshness`
6. `## Residual Ambiguities`
7. `## Recommendation`

If no contradictions are found, say `none` in `## Contradictions Found`.
