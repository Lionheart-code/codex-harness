# Output Format: Harness Audit

Return Markdown with these sections in this order:

1. `## Audit Scope`
2. `## Boundary Findings`
3. `## Workflow Findings`
4. `## Source Trace`
5. `## Skill Risk Check`
6. `## Future-phase Creep Check`
7. `## Recommendation`

`## Recommendation` must state `keep`, `defer`, or `split`.
